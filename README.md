# ⚡ Dekal Relay

Клиентский **NeoForge** мод для Minecraft, перехватывающий процедуру авторизации (`authenticateServer`) и перенаправляющий проверку сессии на собственный сервер аутентификации **Dekal**.

> [!NOTE]
> Мод работает **только на стороне клиента** и заменяет стандартные запросы к `sessionserver.mojang.com` на собственный бэкенд (`/session/minecraft/join`).

---

### 🚀 Как это работает

```text
Minecraft Client ──[ Dekal Relay ]──► POST /session/minecraft/join ──► Dekal Auth Server
```

1. Клиент перехватывает хэндшейк шифрования при входе на сервер.
2. Отправляет токен, UUID и хеш сессии (`digest`) на URL авторизации Dekal.
3. При ответе `200` / `204` вход успешно продолжается без обращения к серверам Mojang.

> [!IMPORTANT]
> Для игры с `online-mode=true` на стороне сервера Minecraft **обязательно** должен быть установлен парный серверный модуль **Dekal Transmitter** (или настроена сверка сессий через ваш бэкенд), иначе сервер отклонит вход с ошибкой невалидной сессии.

---

### 🔌 Совместимость

> [!TIP]
> **Simple Voice Chat** и другие сетевые моды работают **из коробки**. Dekal Relay не затрагивает обмен UDP-ключами и внутренние каналы модов.

---

### ⚙️ Сборка

* Требуется **Java 21+** и **NeoForge 26.1.2+**.

```bash
./gradlew build
```
Готовый мод появится в `build/libs/`.

---

> [!WARNING]
> Адрес сервера авторизации по умолчанию зашит в [Config.java](src/main/java/btxds/dekal/relay/Config.java). Перед сборкой под свой проект убедитесь, что указан корректный домен.
